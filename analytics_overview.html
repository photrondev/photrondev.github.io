The core advantage

The engine does the work. The LLM writes the metadata.

For system integrators

Deliver a customer's vision app in days, not a software project

Everything above is scriptable, so an integrator can build a complete solution (cameras, detection, events, dashboards and reports) without Photron engineering time. The running cost stays low and predictable, which makes fixed-price quotes safe.

 acme_gate.py · iw_app
from iw_app import App, Detect, rtsp, notify, todo

app  = App("acme.gate", "Acme gate", mode="demo")
gate = app.camera("CAM-01 Gate", live=rtsp("rtsp://10.0.0.5/stream"),
                  demo="${assets}/verticals/loitering_example.mp4")
gate.zone("apron", "5%,40%,70%,40%,70%,90%,5%,90%", use=["loitering"])
people = gate.add(Detect.yolo("Gate people"))
loiter = gate.add(Detect.loitering("Gate loitering", people, live_s=120))
gate.record("Gate recorder", "gate", loitering=loiter.alarm, people=people["numDetects"])

events = app.alarm_events("Security events", table="events", hold_s=2, clip_s=10)
app.event(gate, loiter, severity="medium", hold_s=5)
app.add(notify.email("Security email", recipients=todo("Who gets alerts?")))
