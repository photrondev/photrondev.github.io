1. AI Studios Overview

Infini-Workflow provides two tightly integrated, specialized studios for high-fidelity dataset creation and automated machine learning preparation: the AI Labeling Studio and the Video Segmentation Studio, complemented by the interactive Video Splitting Studio for heavy high-speed sequences, and the Fine Tuning Studio for native model optimization.

What are the AI Studios?
Use the studios as a connected workflow: label and prepare data, split long sequences when needed, and fine-tune models from the resulting dataset.

2. AI Labeling Studio

The AI Labeling Studio is a specialized annotation environment built for compiling premium quality ML dataset corpora. It combines an interactive vector/raster edit canvas, sequential frame propagation, and automated checkpoint managers to facilitate pixel-perfect labeling.

Task Types Supported

  • Detection: Draw rectangular bounding boxes around interest targets to train regression-based localization models (e.g., YOLO v8).
  • Instance Segmentation: Manage individual multi-class object instances with automated outline tracking and custom labeling.
  • Image Segmentation: Pixel-level annotations (semantic/binary masks) for isolating fluid boundaries, fractures, or complex shapes.

Labeling, Tracking, & Navigation

Annotate frames by clicking the Edit button on an extracted frame directory. Once in the viewer, select your active class, use a path tool (such as Add Rectangle or polygon points), and click and drag to define your shape. Switch classes as needed, and save your progress.

Live Labels Summary & Report Verification

To provide absolute transparency over your dataset's annotation status, AI Labeling Studio integrates a live, auto-updating Summary & Report column on the results list (right panel):

  • Interactive Class Summary: Each frame row displays a live summary of the labels/classes drawn on that frame (e.g., Apple, Banana). No need to open each frame to know what has been annotated.
  • Auto-Segmentation Badge: Frames automatically tracked via SAM2 propagation display a distinct, high-visibility AUTO badge, signifying they are verified machine-generated candidates.
  • Error Reporting & Validation: If a frame contains labels pointing to classes that no longer exist or are out of bounds, the summary column instantly displays a striking INVALID warning badge, preventing faulty data from contaminating training.

Dataset Fine-Tuning & Weights Compilation

After compiling labeled sequences, use the Fine Tuning controls to compile native models (e.g. YOLO, UNet) based on your custom annotations.

  • Model & Training Specs: Define neural architecture backbone size, evaluation/training split ratios, learning rate, and epochs count.
  • Multi-Video Compilation: Click the Fine-Tune button to invoke a project-wide Fine-Tune Videos selection dialog. This tool shows all videos inside your folder, with thumbnails, and memorizes your checked video directories using persistent cookies.
  • Real-time Status Log: Stream console progress, epoch completion, active validation splits loss curves, and background training loops directly inside the interface.
  • Inference Node Generation: Once a training run successfully completes, click "Create Inference Node" to drop a pre-configured native ML Inference block containing your compiled weights directly into your core workspace.

3. Video Segmentation Studio

The Video Segmentation Studio serves as the central control room for managing raw media sources, converting film into discrete frames, and preparing frame sequences. It features rich asynchronous processing and high-performance background pipelines.

Workspace Organization

Your video corpus is managed inside an interactive spreadsheet overview, providing clear indicators for Thumbnail Preview, Sequence Filenames, and Lifecycle Actions:

  • Thumbnail Zoom: Hover your mouse cursor over any video thumbnail on the left column to instantly reveal an interactive full-size floating hover preview of the video frame.
  • Filename Paths: Displays file sequences or active folders within the current project repository.
  • Lifecycle Action Dashboard: A set of quick-action control buttons corresponding to the video state.

Video Actions and Workflow Icons

Each video entry displays a set of actions depending on whether it's a raw file, a processed sequence, or a preprocessed variation:

Icon Action Function & Backend Flow

Re-Extract / Refresh Clears previous frames and triggers re-extraction. Handy when original source files change or parameters are adjusted.

Background Frame Tracking (SAM2)

To keep labeling pipelines interactive, long-sequence frame propagation using SAM2 can be offloaded to a background thread directly from the annotation editor:

  • Run in Background: Click the "Run in Background" button inside the tracking modal to close the editor and resume other workflow actions.
  • Live Progress Banner: A prominent tracking banner resides at the top of the Video Segmentation Studio showing a spinning gear, sequence name, and completion percentage alongside a real-time progress bar.
  • Concurrent Operations: While background propagation runs, you can create variations, delete sequences, or perform metadata changes on other videos.

Dataset Preprocessing & Sequential Duplication

To expand your annotations synthetically, the Variations Panel offers powerful single-click duplication and global bulk propagation:

  • Header-Level Controls: The "Generate" and "Back to Video Segmentation Studio" buttons are neatly integrated at the header level of the variations window, offering maximum screen real estate.
  • Delete All Except Copy: Clicking "Delete All Variations" deletes all augmented variations while keeping the primary - Copy directory fully intact on disk, letting you reset your augmentation pipelines without losing key annotations.
  • Sequential Duplication to ALL: The "Duplicate Variations to All" action copies the configured variations of your selected source movie sequentially across all other processed/labeled movies in the active workspace.
  • Silent Fail-Over Guard: The sequential duplication queue is built with bulletproof error handling. Unlabeled movies, empty mask states, or missing directories are silently and gracefully bypassed, ensuring the bulk queue completes without halting or throwing error blocks.
  • Dual-Progress Visualizer: An interactive overall progress tracking overlay appears during bulk duplication, detailing the current active task (e.g., Task 2 of 5) and progress percentage in real time.

Batch Processing & Automated Queue Management

To fast-track pipelines involving large video libraries, the Video Segmentation Studio integrates Batch Processing:

  • Wipe & Clean Rebuild: Toggle the "Clean preprocessed data" option to wipe previously completed cookies and cache states. This ensures that the parallel processor reconstructs all target frames and augmented variations from scratch, eliminating dirty-state cache discrepancies.
  • Workload Parallelization: Specify the "Number of parallel batches" to control how many independent background python processes are spawned. This splits the dataset across parallel processors to saturate multiple computing pipelines.
  • Hardware Telemetry: View the read-only "Number of devices (GPUs)" field to quickly verify the total discrete graphics processing units available in the host environment.
  • Chained Training Execution: By checking "Automatically start training after data expansion", the pipeline creates an automated feedback loop, directly triggering model fine-tuning runs using the configured hyperparameters once parallel data expansion completes.
  • Graceful GUI Exit & Dedicated Terminal Spawn: Clicking the primary "Do you want to EXIT and start Batch Preprocessing?" button serializes the configuration, closes the local web server GUI, and immediately spawns a high-priority, dedicated standalone terminal window to execute the heavy processing workload. The browser window is then gracefully redirected to Photron's home portal.

Video Studio Setup & Discord Integration

To customize frame handling and receive remote alerts during long batch sequences, the **Video Studio Settings** modal provides high-fidelity options:

  • Interactive Setup Dialog: Accessible via the gear icon () in the Video Segmentation Studio control bar. Tweak settings on-the-fly and save them persistently.
  • Frame Deduplication Control: Specify a custom threshold (range: 0 - 1000, default: 1) to filter out redundant, static, or identical frames during video processing. This significantly reduces annotation workload by eliminating duplicate image sequences.
  • Discord Notifications Integration: Toggle "Enable Discord Notifications" and supply a custom **Discord Webhook URL**. The backend automatically monitors background batch preprocessing progress and training metrics, periodically posting structured rich-embed logging updates directly to your Discord channel.
  • Persistent Cookie-State Retention: All settings (deduplication threshold, Discord toggles, and webhook URLs) are serialized securely in cookies. This retains your precise preferences across page reloads and future sessions.

4. Video Splitting Studio

The Video Splitting Studio is a dedicated high-fidelity interface designed to manage heavy, long, or high-speed video sequences. Because annotating thousands of frames linearly is impractical, the Splitter allows you to clip precise frame spans and compile them into shorter, highly manageable chunks.

Automated Redirection

You do not need to launch the Splitter manually. Inside the Video Segmentation Studio, clicking Process on any raw video file containing more than 240 frames will automatically open the full-screen Video Splitting Studio interface.

Features and Interactive Scrubber Controls

  • Real-time Frame Scrubber: Drag the premium timeline range slider to scrub through frames instantly. The viewer shows real-time frame index badges and original resolution specifications.
  • START & END Boundary Pins: Click Set Start Boundary or Set End Boundary to drop green (START) and red (END) marker pins directly on the scrubber track. Only frames inside this custom boundary will be processed.
  • Custom Chunking Size: Specify the maximum frames per output sequence part (default: 240 frames). The splitter calculates exactly how many discrete chunk sequences will be compiled.
  • Temporal Frame Skipping: Apply a frame step/skip ratio (e.g., sample 1 frame every 5 frames) to temporally downsample high-speed video clips, dramatically reducing redundant data while preserving key kinematics.
  • Live Estimation Breakdown: As you tweak boundaries, chunks, or skips, a live dashboard recalculates total chosen frame span, frame sampling, exact frame count to extract, and compiles a complete output part name list dynamically (e.g. clip_1_split.mp4, clip_2_split.mp4).
  • High-Performance Extraction: Click Proceed Split to execute high-speed splitting. The overlay triggers background extraction, automatically creating individual virtual video files inside your main Video Segmentation Studio table list once completed.

5. Fine Tuning

The Fine Tuning provides a powerful, web-native interface to train, validate, and optimize state-of-the-art machine learning models directly on your custom-labeled datasets. Rather than exporting your data and writing complex boilerplate training scripts, you can initiate high-performance model training in one click, monitor metrics in real time, and deploy your custom weights immediately within your workspace.

1. Dataset Preparation & Rules

Before initiating training, you must ensure your annotated dataset meets the system requirements. The system enforces strict validation gates:

  • Data Finalization: All bounding boxes, polygons, and segment masks must be fully saved and finalized. The system searches SQLite caches to compile the raw training matrix.
  • Validation Check Rules: Training cannot begin if no frames have been annotated. The system will throw a validation error dialog and block execution if the labeled frame count is zero, preventing wasted computing overhead.
  • Automatic Class Mapping: Custom classes defined during label creation are dynamically numbered and mapped (e.g., class_0: cell, class_1: nucleus) to generate compatible YAML configuration descriptors automatically.

2. Hyperparameter Configuration

The studio exposes crucial learning parameters in a visual dashboard, allowing you to fine-tune the training process:

  • Model Size & Backbone Selection: Choose from standard neural backbones depending on your speed and resource needs (e.g., YOLOv8 Nano (n) for real-time edge performance, YOLOv8 Small (s) or Medium (m) for complex multi-class detection).
  • Train/Val Split Ratio: Fine-tune the percentage of frames reserved for validation (typically 80/20 or 90/10 split). This partitions your dataset cleanly, shielding the validation set to monitor overfitting.
  • Epoch Control: Specify the total training epochs (range: 10 - 500). Epoch controllers allow you to govern the model's iteration density over your target corpus.
  • Batch Size & VRAM Optimization: Set the number of images processed concurrently per backward gradient update (e.g., 8, 16, 32, or 64).
    • Higher Batch Sizes: Maximizes GPU hardware utilization, speeds up overall training duration, and provides more stable gradient updates. Best suited for high-end GPUs.
    • Lower Batch Sizes: Dramatically reduces the active VRAM footprint. If your system encounters a CUDA Out of Memory (OOM) crash, downsize the batch size parameter to 8 or 4.
    • Dynamic Auto-Batching: Setting the parameter to Auto commands the trainer to run initial dummy dry-run passes on your hardware to determine VRAM ceilings, automatically picking the largest safe batch size.

3. Initiating Training & Multi-Video Selection

To compile broad generalization capabilities, models should train on varied datasets. The Fine Tuning Studio supports compiling multi-video datasets with seamless UX:

  • Project-Wide Multi-Video Dialog: Clicking the training initiation trigger opens a dedicated workspace-wide sequence selection dialog. You can select exactly which labeled clips are included in the compilation run.
  • Visual Thumbnail Grid: The selection dialog displays visual thumbnail previews, name tags, frame counts, and active annotation counts for each video clip to easily track labeled sources.
  • State Retention via Browser Cookies: Your dataset selection preferences, model configurations, and target selections are serialized in secure browser cookie states. Refreshing the dashboard or reopening the studio retains your exact working choices, eliminating repetitive setup.

4. Batch Training & Standalone Execution

When initiating a project-wide multi-sequence training operation in batch mode, the selection dialog transforms into a high-performance, standalone compiler setup panel:

  • Standalone Mode Indicator: The dialog modal displays a dedicated terminal icon () in the header, indicating that the training workload will run in high-priority background compilation mode.
  • Delete Prior Training Checkpoint: A red checkbox option appears in the dialog footer: "Delete prior training checkpoint". Checking this clears any saved weights from previous neural runs, forcing the compiler to optimize parameters purely from a clean, unbiased initial state.
  • Graceful Shutdown & Standalone Launch: The primary trigger button is styled in high-visibility crimson: "Do you want to EXIT and start training?". Clicking this initiates the backend process, closes INFINIWORKFLOW (to allocate 100% of host VRAM and CPU to ML training), and launches a dedicated standalone console window where training is optimized in parallel.

5. Real-Time Training Monitoring

Once you trigger the run, the dashboard transitions into an interactive telemetry and performance viewport:

  • Live Log Streaming: Watch the stdout logs directly inside the manual pane or fine-tuning logs widget. The system streams actual PyTorch training steps, batch processing speeds, and background GPU telemetry.
  • Interactive Progress Indicators: Real-time progress bars show overall completion percentage, current epoch index, and estimated remaining time (ETA).
  • Dynamic Loss Curve Evaluations: A live-updating telemetry chart plots training loss, validation loss, mean Average Precision (mAP50, mAP50-95), and recall across epochs, helping you visually pinpoint overfitting or convergence plateaus instantly.

6. Deployment and Canvas Integration

When training concludes, your optimized model is packaged and made available for immediate production:

  • Weight Compilation: The pipeline extracts the highest-scoring parameters (best.pt) along with evaluation metrics tables.
  • Native ML Inference Node: With one click, compile a custom ML Inference Canvas node containing your newly trained model. This node inserts directly into your active flowgraph workspace.
  • Immediate Inference Loop: Connect raw video streams or high-speed frames into this custom Canvas node to run inference using your personalized model parameters immediately, completing the automated feedback loop.

AI Tracking & Mechanics Pro-Tips:

  • Drift Prevention: Always verify your path after manually overriding a keyframe, as the system clears dependent "AUTO" segments to maintain sequence integrity.
  • Performance: Images are processed at 1024px using the FastSAM-s model for optimal balance between speed and precision.
  • Dataset Integrity: All AI-assisted labels must be finalized or vectorized before the final training export to ensure the ML model receives high-quality ground truth.

Offline & Custom Training:

Need to run training on a dedicated GPU cluster or your own local machine? Our platform provides full transparency and exportability:

  • Training Script Export: Once you initiate a fine-tuning job, you can navigate to the Code output of the Fine Tuning node in the workflow.
  • Downloadable Assets: You can download the complete training script and your finalized dataset package directly from the interface.
  • Run Anywhere: Execute the exported script in any environment supporting our framework, allowing you to bypass platform limitations and utilize your own hardware resources for heavy training workloads.
