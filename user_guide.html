Measurement & Calibration

Tools

Ruler, Angle, Angle2, Multi (polyline), Radius and Diameter overlays drawn directly on the video.

Calibration plane

A 4-point quad converts pixel measurements into real-world units via perspective homography.

Closing the dialog

Closing Measurement also hides every drawn shape from the viewer. It's mutually exclusive with Stabilization — opening one closes the other.

Stabilization

Tracking modes

Choose "One Point" or "Two Point" tracking, with adjustable ROI and Template sizes.

Track Backward / Forward

Trace the motion path across the timeline to build the stabilization transform.

Exclusive with Measurement

Only one of Measurement / Stabilization can be open at a time.

Keystone Correction

Drag the four handles ("K0"–"K3") to warp perspective, and use "Reset Keystone" to restore a flat image.

Playback & Timeline

Controls

Play/Pause buttons sit at the top, bottom, or as an overlay inside the viewer, with a scrubbable timeline slider. Press Space anywhere in the window to toggle Play/Pause.

Set Frame Number (if enabled)

A crosshair-style button next to the timeline opens a small calculator-style keypad for typing an exact frame number to jump straight to it.

Multi-View (Spawn)

Launch and tile extra copies of this application ("followers") alongside the original ("master") from Windows > Multi-View, using the "2x1"/"2x2" quick layouts or "Terminate Spawns" to close them all.

Always synced

Window tiling, the focus-highlight border style, the active Theme, and the UI Language always follow the master.

Configurable sync

Preferences > Multi-View > Sync (master only) toggles Frame, Pan/Zoom and Channels independently — all on by default.

Timeline switches to Embedded

The master's Timeline Position is forced to "Embedded" the moment the group tiles, and restored automatically once every follower is closed.

Bidirectional Timeline (optional)

Off by default (Preferences > Multi-View > Sync). When on, every spawned window gets its own playback bar, and pressing Play/Pause or scrubbing on any one of them - master or follower - takes over and drives the whole group.

Logging

If you run into a problem with this application, enabling Advanced Logging and sending in the log file is the fastest way to help diagnose it.

1. Turn it on

Open Preferences > Logging and check Advanced Logging. The dialog also shows you the exact log file path.

2. Restart the app

Close and relaunch so the more detailed startup logging is active, then reproduce whatever issue you ran into.

3. Send the log file

A single file is written fresh on every run - just attach that one file when you report the issue.

A basic log is always written, even with Advanced Logging off. The file lives at %LOCALAPPDATA%\<AppName>\logs\<AppName>.log on Windows (macOS/Linux use the equivalent per-user logs folder), and is shown in full in Preferences > Logging.
